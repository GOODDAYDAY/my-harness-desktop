工具来源说明：绿色 = pi 底座内置工具，蓝色 = 来自已启用的 extension。 extension 禁用后，其贡献的工具从列表消失。
设计要点
数据模型
• ToolInfo — 工具元数据(id/name/source)
• ToolGroup — 工具组(id/name/toolIds/builtIn)
• SessionToolConfig — 会话级配置(mode/enabledGroupIds)
• 工具组存储: ~/.pi-desktop/config/tool-groups.json
• 会话配置存储: plugin config 按 sessionPath 索引
过滤应用
• 理想: 新增 get_tools + set_tool_filter RPC
• 过渡: prompt 前注入系统指令(软过滤)
• 粗粒度: enable/disable extension + restart
• 默认全开,仅自定义模式时过滤
交互原则
• 设置页管组定义,右面板管会话级切换
• 切组开关即时生效,无需保存按钮(framework manual 模式)
• "应用到当前会话" → 下次 prompt 时生效
• 新会话继承上次该 cwd 的配置(或默认全开)
插件架构
• 新插件 tool-manager
• contributes.settings → 工具组管理页
• contributes.sidePanel → 会话级工具快切 Tab
• saveMode: "manual"(实时生效,无 dirty/浮层)
• 需要 rpc:bash 或新增权限声明
