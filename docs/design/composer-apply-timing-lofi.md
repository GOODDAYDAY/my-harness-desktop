# composerApplyTiming 低保真对比

## 场景 A：正在流式生成时点选（最强差异点）

### A-1 immediate（现状）
```
┌────────────────────────────────────────┐
│ ⏺ assistant                            │
│ ▕ 收到第一条差分就差分…（流式中）▎      │
│ ▕ ▍                                    │
│ ╔══════════════════════════════════════╗ │   ← ✗ 插在生成中途
│ ║      ──── 模型 → openai/gpt-5 ─────╢ │      历史看起来"半路换将"
│ ╚══════════════════════════════════════╝ │
│ ▕ 收到第一条差分就差分…（继续流式）▎    │
│ ▕ ▍                                    │
├────────────────────────────────────────┤
│ [🧠 gpt-5      ▾ ]  [⚡ high     ▾ ]  │  ← 点选那一刻打的条，和流式打散
└────────────────────────────────────────┘
```

### A-2 onSend（默认）
```
┌────────────────────────────────────────┐
│ ⏺ assistant                            │
│ ▕ 收到第一条差分就差分…（流式中）▎      │
│ ▕ ▍   （完整生成，无打断）              │   ← ✓ 不打断
│ ▕ ▍                                    │
├────────────────────────────────────────┤
│ [🧠 gpt-5      ▾ ]  [⚡ high     ▾ ]  │  已记忆，无动作
└────────────────────────────────────────┘
         ↓ 随后按下发送 ↓
┌────────────────────────────────────────┐
│ ⏺ assistant（上一条，完整收尾）        │
│ ╔══════════════════════════════════════╗ │
│ ║        ──── 模型 → openai/gpt-5 ────╢ │   ← ✓ 正好落在问题之前
│ ╚══════════════════════════════════════╝ │
│ ⏺ 你                                   │
│ ▕ 这个问题用 gpt-5 答                    │
└────────────────────────────────────────┘
```

└────────────────────────────────────────┘

         ↓ 3 分钟后发送 ↓

│ ⏺ assistant（上次聊天收尾）            │

│ ║        ──── 模型 → openai/gpt-5 ────╢ │
│ ╚══════════════════════════════════════╝ │

## 场景 C：底部 composer 显示（两模式一致）

```
┌─ composer ─────────────────────────────┐
│ ⏶                                      │
│ 发一个消息…                            │
│                                        │
│ ⏷  [🧠 gpt-5 ▾]  [⚡ high ▾]  [发送 ↵]│
│                                         │
└────────────────────────────────────────┘

immediate：左下角 = 已应用的事实
onSend    ：左下角 = 已记忆的偏好（本轮 send 才落盘）
```

---

## 分隔线本身（两模式共用一个渲染，无差别）

```
─────────────── 模型 → openai/gpt-5 ───────────────
─────────────── 思考强度 → high ────────────────
```

差别只有**它落在哪**，不是它长什么样。
