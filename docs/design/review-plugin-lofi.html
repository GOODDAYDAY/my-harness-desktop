用户说偶发 401 且测试全绿,优先怀疑 token 过期竞态与时区/时钟漂移……
偶发 401 而测试全绿,最常见的根因是 token 刷新的竞态条件:并发请求同时发现 token 过期,各自触发刷新,旧 token 被服务端作废后,仍在途的请求就带着死 token 撞上 401。测试全绿是因为单线程跑不到这条竞态路径。

建议先跑一遍带并发压测的集成测试复现,我先用你仓库里的测试脚本验证下现状:

如预期,全绿。修复方向有两个:给刷新加单例锁(同一时刻只允许一个刷新在途),或者在 401 时透明重试一次。我倾向前者,锁住在根源。
